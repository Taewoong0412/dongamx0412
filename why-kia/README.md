# WHY KIA GAMES

동아MX AI실무과정에 약 한 달간 참여한 팀 whyError의 미니프로젝트 웹사이트입니다.
야구를 좋아하라고 강요하기보다 좋아하게 될 수 있는 첫 경험을 전합니다.

## 실행 / 다운로드
GitHub에서 **Code → Download ZIP**을 선택하고 압축을 풉니다.
`why-kia/index.html`을 Chrome/Edge에서 여세요. 이 README가 들어 있는 폴더를 직접 받았다면 같은 폴더의 index.html입니다.
브라우저가 로컬 iframe을 제한할 때는 이 폴더에서 `python -m http.server 8000` 후 http://localhost:8000 을 여세요.
PC 키보드·마우스 플레이를 권장합니다. 포털은 모바일 반응형입니다.

## 메뉴와 게임
- 홈: 추천 코스, 액션·3D·퍼즐 필터, 게임 5종 바로가기
- 팀 소개: 정태웅 / 홍나겸 / 나성진 / 최진철 / 이정현, 역할과 학습 과정
- 프로젝트: 팀 제공 설명에 기반한 분석 여정 8단계, 해석의 한계와 향후 계획
- 데이터 분석과 처리: 실제 노트북 코드·저장된 출력, 최종 CSV 집계, 원본 PNG
- 게임: 공 잡 기 / 공피하기 / 갸서바이벌 / 갸천성 / 미니게임·이닝체험
- 튜토리얼: 별도 분석 체험 페이지와 실행 링크 (메인 5개 목록에서 제외)

## 반영한 원본
- 최신 `미니프로젝트 게임 (2).zip`: 4개 메인 게임 + 튜토리얼. 이전 ZIP과 파일 내용이 같고 일부 폴더명만 변경됨.
- 추가 `갸찬성.html`: 웹사이트에서는 요청한 표시명 `갸천성`으로 연결. 이미지 내장, 외부 다운로드 불필요.
- `미니프로젝트.zip`: Data/processed/final CSV·PNG, 선수 분석 중첩 ZIP, 주피터 노트북.

## 노트북과 데이터 검증 범위
노트북 전체를 재실행하지 않았습니다. 입력 원본 JSON·Parquet가 모두 제공되지는 않았습니다.
코드와 저장된 출력은 직접 읽었으며, 최종 CSV를 독립적으로 검사했습니다.
- 2024 KBO 정리: 노트북 798건 중 연기 78건 제외 → 720행. 최종 CSV 720행/10열, game_pk 중복 0, 점수 결측 0 확인.
- KIA PBP 최종 CSV: 타자 58,927행, 투수 58,744행. 2026년 마지막 날짜는 7월 26일.
- 네일: 전체 상대팀 6,742구. 7개 구종 투구 수가 노트북 저장 출력과 일치.
- 포털 구종 그래프: 이번 최종 CSV의 전체 상대팀 기록을 재집계. 3이닝 게임의 KT 맞대결 범위와 구분.
- 5단 검증 CSV: 2024 142행 / 2025 142행 / 2026 144행 (합계 428). 2026 자료는 10월 12일까지.
- 날씨 노트북: 432경기 입력 CSV를 참조하지만 그 CSV와 저장된 실행 출력이 없어 수치 재현은 보류. 428행 검증표와 동일한 범위로 취급하지 않음.
- 야구와 무관한 Untitled.ipynb 및 체크포인트는 사례에서 제외.
- 관측 패턴은 인과관계, 현재 소속, 예측 정확도를 보장하지 않음.

## 통합 시 변경
게임 코어는 원본을 사용했습니다. 포수 게임에서 참조하는 catcher_glove_pov.png는 모든 ZIP에 누락되어, 깨진 이미지 대신 글러브 문자 표시로 대체했습니다. 추후 원본 이미지로 복구할 수 있습니다.
서바이벌의 외부 폰트 링크는 시스템 글꼴로 대체해 오프라인에서도 실행됩니다.
게임 실행 래퍼는 목록 복귀와 전체 화면 버튼을 제공합니다. 게임 원본의 규칙이나 난이도는 새로 변경하지 않았습니다.

## 구조

- assets/data.js: 이번 CSV 기반 구종 집계
- assets/notebooks.js: 실제 노트북 코드 및 출력 발췌 (HTML 이스케이프 후 표시)
- assets/inventory.js: CSV 행 수·열 수·날짜 범위
- assets/analysis: 원본 PNG 6종
- assets/screens: 실제 게임 화면 썸네일
- downloads: 노트북 3종과 검증용 CSV
- play.html: 허용된 게임 ID만 실행하는 iframe 래퍼
- games: 게임 6종
- checks: 브라우저 검증 스크립트

## 검증

모든 게임의 모든 레벨을 완주하거나 장시간 밸런스를 검증한 것은 아닙니다.
